# Windows 원클릭 설치 / Windows one-click setup

**NAI-AI-CharacterStudio-Windows-v1.2.3d.zip**을 받으세요. GitHub가 자동 제공하는 `Source code` ZIP이 아닙니다.

1. ZIP 전체를 압축 해제합니다.
2. 폴더 안의 **set_up.exe**를 실행하고 **1 셋업 시작**을 누릅니다.
3. 설치가 끝나면 **2 실행**, 이어서 **3 실행확인**을 누릅니다.
4. 다음부터는 **NAI_Studio.exe → 실행**으로 시작합니다.

Windows 10/11 x64용입니다. Python·Node를 따로 설치할 필요가 없습니다. Python·패키지·화면 파일을 포함하고, 셋업에서 모델·추론 엔진·태그 DB·필요한 Microsoft 실행 구성 요소를 다운로드합니다. 기본 장치는 NVIDIA CUDA 12.4이며 Vulkan·CPU는 직접 선택할 수 있습니다. 첫 설치에는 인터넷과 모델을 저장할 공간이 필요합니다. 실제 GPU·모델 동작은 사용자의 장비에서 실행확인으로 검사합니다.

---

Download **NAI-AI-CharacterStudio-Windows-v1.2.3d.zip**, not GitHub's automatically generated `Source code` archive.

1. Extract the entire ZIP.
2. Run **set_up.exe** and click **1 셋업 시작** (Start setup).
3. After installation, click **2 실행** (Run), then **3 실행확인** (Verify).
4. On later runs, open **NAI_Studio.exe** and click Run.

For Windows 10/11 x64. No separate Python or Node installation is needed. Python, packages, and the built frontend are bundled. Setup downloads the model, inference engine, tag database, and required Microsoft runtime. The default device is NVIDIA CUDA 12.4; Vulkan and CPU can be selected manually. Initial setup needs internet access and storage for the model. Real GPU/model operation is checked on your machine through Verify.
