# 의존성 목록 / Dependency inventory

설치된 배포 파일과 잠금 파일의 메타데이터를 기준으로 작성했습니다. / Generated from installed distribution metadata and lockfiles.

npm 플랫폼별 선택 의존성은 잠금 파일에 포함되지만 현재 환경에 설치되지 않은 항목의 원문은 동봉하지 않았습니다. 다운로드되는 패키지는 자체 고지를 유지합니다. / Platform-specific optional npm dependencies are listed from the lockfile; texts for packages not installed here are not bundled. Downloaded packages retain their own notices.

Python 테스트 의존성은 `requirements-test.lock`에 별도로 고정되어 있으며 실행 소스에 패키지 자체를 포함하지 않습니다. / Python test dependencies are separately pinned in `requirements-test.lock`; their package code is not included in this source distribution.
